# LaTeX

Nesta pasta (LaTeX), será exposto os principais objetos e comandos da linguagem de texto LaTeX.

---

## Porque aprender LaTeX?

O LaTeX é uma ferramenta muito importante para a pesquisa científica, em que possibilita diversas contruções de textos e arquivos, pois você escreve em formato de código para o compilador processar e gerar um arquivo.
Em comparação com outros editores de textos como o word, no LaTeX você tem mais liberdade de formatação e escrita pois, ao inserir um comando você já altera por completo
